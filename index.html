01 / Architecture

바뀌어도 흔들리지 않게

Hexagonal · DDD로 비즈니스 로직을 가운데 두고 DB, 외부 API, LLM은 포트와 어댑터 뒤에 둡니다. 클라우드 API를 로컬 모델로 바꿀 때도 도메인 코드는 그대로 두고 어댑터만 추가했습니다.

02 / Harness

AI가 일할 틀을 짓는다

사실은 DB가, 문장화는 LLM이 맡게 나누고, 사람이 정답을 정의한 평가셋으로 검증합니다. 모델이 실패하면 외부 API로, 그마저 실패하면 결정론적 규칙이 받아냅니다.

03 / Human-in-the-Loop

책임은 사람이 진다

AI 에이전트에게 구현을 맡길 때도 작업의 위험도에 따라 검토 강도를 나누고, 최종 판단과 책임은 사람이 집니다.

01개인 · 기획부터 배포까지

샤일록의 법정Shylock

플레이어의 선택에 LLM 캐릭터들이 실시간으로 반응하는 법정 추리 웹 게임. 인증 서버, RAG, 로컬 LLM 서빙, 프로덕션 배포까지 혼자 구축했습니다.

  • 인물 관계를 원문 근거가 달린 그래프(노드 7 · 엣지 17)로 모델링해 사실은 DB가, 문장화는 LLM이 맡도록 분리
  • 판사 ‘공작’은 LLM judge로 판정하되, 모든 LLM 경로가 실패하면 결정론적 규칙이 판정 — 로컬 모델 → 외부 API → 규칙 3단 폴백
  • API 비용 월 $200을 줄이려 평가 기준을 통과한 26B 오픈소스 모델을 직접 서빙. 도구 호출 에이전트는 호출하면 안 되는 상황에서 12/12 호출해 기준 미달로 판정하고 API에 남김
  • 1GB EC2에는 백엔드만, 추론은 맥북 Ollama로 분리해 Cloudflare Tunnel + Zero Trust로 연결 — Hexagonal · DDD · Vertical Slice 구조라 도메인 코드는 그대로 두고 어댑터만 추가
  • Google OAuth + RS256 JWT 인증 서버부터 nginx · Docker Compose 배포까지 직접 구축
