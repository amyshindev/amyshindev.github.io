01 / Architecture

바뀌어도 흔들리지 않게

핵심 로직은 가운데에 두고, DB나 AI 모델은 바깥에 끼워 쓰는 부품처럼 다룹니다. 그래서 비싼 API를 무료 로컬 모델로 바꿀 때도 핵심 코드는 그대로 두었습니다.

02 / Harness

AI가 일할 틀을 짓는다

사실 확인은 데이터베이스가, 말로 풀어내는 일은 AI가 맡도록 역할을 나눕니다. AI가 실패해도 다른 모델과 규칙이 차례로 받아 주니 서비스가 멈추지 않습니다.

03 / Human-in-the-Loop

책임은 사람이 진다

AI에게 코딩을 맡겨도, 중요한 작업일수록 더 꼼꼼히 검토합니다. 마지막 판단과 책임은 언제나 사람의 몫입니다.

04 / Fractal

모든 기능을 같은 모양으로

기능마다 똑같은 구성의 파일 묶음으로 만듭니다. 모양이 같으니 AI가 헷갈리지 않고, 실수해도 그 묶음 안에서만 영향이 납니다.

05 / Patterns

if문 대신 GoF 디자인 패턴

조건문을 줄줄이 늘어놓는 대신 GoF의 디자인 패턴(Strategy · State · Factory 등)으로 정리합니다. 새 기능을 붙일 때 기존 코드를 덜 건드리고, AI에게도 한 단어로 의도를 전할 수 있습니다.

06 / Verify

완성의 기준부터 정한다

무엇이 되면 ‘완성’인지 테스트로 먼저 적고, 그 테스트를 통과시키는 식으로 일합니다. AI가 만든 코드도 ‘된 것 같다’가 아니라 ‘테스트를 통과했다’로 확인합니다.

01개인 · 기획부터 배포까지

샤일록의 법정Shylock

플레이어의 선택에 LLM 캐릭터들이 실시간으로 반응하는 법정 추리 웹 게임. 인증 서버, RAG, 로컬 LLM 서빙, 프로덕션 배포까지 혼자 구축했습니다.

서비스 바로가기 GitHub
  • 인물 관계를 원문 근거가 달린 그래프(노드 7 · 엣지 17)로 모델링해 사실은 DB가, 문장화는 LLM이 맡도록 분리 — 관계 저장소는 환경변수 스위치로 Postgres(재귀 CTE) ↔ Neo4j 교체 가능
  • 그래프 유무 ablation(조건별 n=42)에서 멀티홉 관계 질문 정답률 21% → 100%(Fisher p=3.6×10⁻¹⁵) — 단일 사실 질문에서는 차이 없음을 함께 확인
  • 판사 ‘공작’은 LLM judge로 판정하되, 모든 LLM 경로가 실패하면 결정론적 규칙이 판정 — 로컬 모델 → 외부 API → 규칙 3단 폴백
  • API 비용 월 $200을 줄이려 평가 기준을 통과한 26B 오픈소스 모델을 직접 서빙하되, 기능별 환경변수 스위치로 문제가 생긴 기능만 즉시 Claude · Cohere로 복귀할 수 있게 설계. 도구 호출 에이전트는 호출하면 안 되는 상황에서 12/12 호출해 기준 미달로 판정하고 API에 남김
  • 1GB EC2에는 백엔드만, 추론은 맥북 Ollama로 분리해 Cloudflare Tunnel + Zero Trust로 연결 — Hexagonal · DDD · Vertical Slice 구조라 도메인 코드는 그대로 두고 어댑터만 추가
  • 같은 임베딩 모델도 EC2(t3.micro)에서 직접 돌리면 CPU 크레딧 고갈로 평균 7.5초(p95 29초) — 맥북(Apple Silicon)에서 돌리고 결과만 네트워크로 받으면 약 13ms로, 추론 위치만 바꿔 약 580배 단축
  • ORM relationship()은 진짜 애그리게이트(Trial–ChoiceHistory) 하나에만 허용하고 나머지 FK는 ID 참조 + 수동 join — AsyncSession에서 로드 안 된 관계를 건드리면 조용한 N+1 대신 즉시 예외가 나는 구조로 DDD 애그리게이트 경계를 지킴
  • Google OAuth + RS256 JWT 인증 서버부터 nginx · Docker Compose 배포까지 직접 구축

라이프 튜토리얼Life Tutorial

청소년이 첫 아르바이트에서 마주할 부당한 상황을 게임으로 미리 겪어 보는 노동권 교육 서비스.

서비스 바로가기 GitHub Pages
  • 방어전 — NPC ‘나사장’에게 자유 텍스트로 반박하며 대응을 연습하는 대화 모듈. 판정 모델은 벤치마크가 아닌 도메인 실측으로 선택 — Gemini Flash-Lite는 틀린 답을 정답 처리하는 치명 오판정을 냈지만 EXAONE 7.8B는 0건(자연어 75발화에서도 위험 오판정 0)
  • 가드 — 근로계약서를 OCR로 읽고 규칙 기반으로 위법 조항을 판정한 뒤, 최종 판단은 상담 기관의 사람에게 연결
  • 리포트 — 인터뷰 답변에서 상담에 필요한 사실을 추출해 기관 전달용 리포트 생성. 156케이스 평가셋으로 3개 모델을 교차 평가해 Gemma3 12B 채택(분류 100% · 값 일치 90.2% · 날조 0건)
  • 법령 · 고시 · 행정해석 1,593개 청크 RAG — 화면의 법령 문장은 LLM이 쓰지 않고 100% DB 원문을 그대로 보여 줘, 틀린 조문이 구조적으로 나올 수 없게 설계
  • 실제 근로계약서(개인정보)를 다루기에 폐쇄망 로컬 추론을 전제로 설계 — 16GB GPU 한 장에 EXAONE과 Gemma를 동시 상주시켜 시연 중 모델 교체를 없애고 OCR은 CPU로 분리. 임베딩 모델이 다르면 벡터가 호환되지 않아 청크마다 온라인 · 오프라인 벡터를 미리 채워 두어, 전환 시 재임베딩 0건
  • 트러블슈팅 — 임베딩 429 지연의 원인이 우리 호출량이 아닌 모델 공용 쿼터임을 실측으로 확인하고, 고정 25초 대기를 지수 백오프로 교체해 방어전 한 턴 28초 → 중앙값 0.4초

REMAKE DAY리메이크데이

“사람은 언제 AI의 제안을 받아들일까?” 실패 → AI 제안 → 사람의 선택 → 규칙 적용 → 재실행으로 이어지는 에이전트 운영 루프를 게임으로 재현하고, 사람의 판단을 데이터로 쌓는 실험형 게임.

서비스 바로가기 GitHub Pages
  • 줄거리 — 매일 멸망하는 대피소의 진짜 정체는 돼지농장. 유저는 끝까지 자기가 사람이라고 믿는다. 멸망할 때마다 규칙을 고쳐 하루를 다시 돌리는 구조가 곧 ‘실패 → 규칙 수정 → 재실행’의 에이전트 운영 루프
  • 유저가 규칙을 직접 쓰거나 AI 제안을 골라 세계에 거는 구조로, 하네스(AI가 따르는 규칙과 틀)를 고치는 사람의 선택을 기록
  • 관찰 결과(사람 플레이 14판) — 적용된 규칙 60건 중 48건(80%)이 AI 제안, ‘원숭이손’ 제안 수락 17/21(81%), 5회차 완주 10/14
  • 수치는 코드가, 판단은 LLM이 — 도메인 계층은 LLM 없이 테스트하는 순수 함수, 코어는 시나리오를 모르는 Hexagonal 구조
